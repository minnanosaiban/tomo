英文を選んで聞き、**自分で書いた解説（Markdown）を、英文のそばから開ける**アプリです。「英文」「解説」「同期」の3つのタブだけで、データは端末の IndexedDB に置き、暗号化して PC とスマホで共有します。

[英文学習アプリ](eng-sentence.md)の「英文」タブと同期の仕組みを引き継ぎ、解説を Markdown で自分で足したり直したりできるようにしました。このページは、その仕組みと、作るうえで判断したことの解説です。

## 英文学習アプリから、何を引き継ぎ、何を変えたか

| | 英文学習アプリ | 英語ノート |
|---|---|---|
| 英文 | 選択 → 学習の2段 | 英文タブだけ（選ぶ・聞く・絞り込む） |
| 解説 | 解析データから、学習画面で組み立てる（自分では直せない） | **Markdown の文章**。自分で書く・直す |
| 登録・AI解析・受信箱 | あり | なし（読み込みと同期だけ） |
| 同期 | 英文・単語・区切り | 英文・解説 |

英文タブの絞り込み（パート・難易度・グループ・ラベル・解説の有無）、シャッフル、行ごとの 1.0 / 0.8 / 0.5 の読み上げ、間と繰り返し、文型や態・時制・相の表示は、元のコードを読んで、そのまま引き継ぎました。英文の検査（`Clean.sentence`）と、足りない項目だけを足す（`Clean.fill`）も同じです。これで、英文学習アプリの英文データを、そのまま読み込めます。

## 解説を、Markdown にした

解析データから組み立てる解説は、見た目がそろう反面、**自分の気づきを足せません**。そこで、解説は、ただの Markdown の文章にしました。

- 追加・編集の画面は、左に書いて、右にプレビューが出る形です。
- `.md` ファイルを読み込んで、解説にもできます。
- 英文学習アプリのサンプル155文には、解析をまとめた Markdown の解説を、あらかじめ作って入れました（文型・文の構造・時制・文法・単語・TOEIC・4択）。入れたあとは、普通の解説と同じで、書き換えられます。

### Markdown の変換は、自分で小さく書いた

ライブラリは使わず、必要な範囲（見出し・箇条書き・表・コード・引用・リンク・太字）だけを、100行ほどで書きました。大事にしたのは、**貼り付けた文章でスクリプトが動かないこと**です。そのため、先に HTML をエスケープしてから、記法を変換します。

```js
function inline(s) {
  const codes = [];
  s = s.replace(/`([^`]+)`/g, (_, c) => { codes.push(c); return "\u0000" + (codes.length - 1) + "\u0000" });
  s = esc(s); // ← 先にエスケープ。ここから先は、<script> も文字として扱われる
  s = s.replace(/\[([^\]]+)\]\((https?:\/\/[^\s)]+)\)/g, '<a href="$2" target="_blank" rel="noopener noreferrer">$1</a>');
  // …太字・斜体など
}
```

リンクは `http` と `https` だけを受け付け、`javascript:` は通しません。コードの中身は、エスケープを2回かけないよう、いったん取り出してから戻します。

## 英文の行から、解説を開く

英文の行の「**解**」を押すと、その英文の解説だけが開きます。

- 解説は、**タイトルが英文と同じ**ものを探して結びつけます（120文字まで）。別の「紐づけ」のデータは持ちません。
- 解説がまだない英文では、タイトルと和訳が入った新規作成画面が開きます。
- 「すべての解説を見る」で、一覧に戻ります。

```js
const noteKey = t => String(t || "").replace(/\s+/g, " ").trim().slice(0, 120).trim().toLowerCase();
noteMap = new Map(notes.map(n => [noteKey(n.text), n]));
```

結びつけを、タイトルだけで持つことにしたので、同期や読み込みで、英文と解説の対応が崩れることがありません。反面、**タイトルを書き換えると、結びつきが切れます**。この制約は、画面と README に書いています。

## 同期

英文学習アプリの同期の設計を、そのまま引き継ぎました。

- 端末で AES-GCM 暗号化してから、Cloudflare の D1 に預けます。鍵は、パスフレーズから PBKDF2（60万回）で作り、取り出せない形（`extractable: false`）で端末に置きます。サーバーは暗号文しか持たないので、Cloudflare からも中身は読めません。
- 送る行の種類は、`sentence`（英文）と `note`（解説）の2つです。前回の同期から変わった行だけを、ハッシュで見分けて送ります。
- 手元で消した行は、戻ってきません（「消した」と伝えるまで、同じ行を受け取らない）。
- スマホは、QR コードで接続します。同期キーを URL の `#` より後ろに入れるので、サーバーには送られません。
- 保管庫は1つだけ作れ、作るときはセットアップコードが要ります。

受信箱（Claude Code などが英文を預ける仕組み）は、このアプリでは外しました。英文と解説は、読み込みで入れます。

## 読み込みと、足りないものだけ足す

「同期」タブから、`.json`・`.csv`・`.txt` を読み込めます。`.json` は、このアプリのバックアップ、英文学習アプリのバックアップ、解析済みの英文、解説だけのファイルを受け付けます。

- 同じ英文があれば、**足りない項目だけ**を足し、状態・ラベル・和訳は上書きしません。
- 同じ ID の解説は、読み込み直しても飛ばします。**自分で直した解説が、読み込みで戻ることはありません**。
